## Usage

```tsx
import { InputOTP, InputOTPGroup, InputOTPSlot } from "@/components/ui/input-otp";

<InputOTP maxLength={4}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
    <InputOTPSlot index={3} />
  </InputOTPGroup>
</InputOTP>
```

Built on [input-otp](https://input-otp.rodz.dev), like shadcn's.

## Accessibility

- One real `<input>` underneath, so paste, autofill (`autocomplete="one-time-code"`) and screen readers work.
- Slots and underlines are visual only.
