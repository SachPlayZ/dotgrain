## Usage

```tsx
import { Bubble, BubbleContent } from "@/components/ui/bubble";

<Bubble align="end">
  <BubbleContent>Yes, and it recolours live.</BubbleContent>
</Bubble>
```

Parts: `BubbleGroup`, `Bubble` (carries `variant` and `align`), `BubbleContent`, `BubbleReactions`. Text always sits on a solid pane; the dither is the mat around it, so it reads in every palette. shadcn's `asChild` on `BubbleContent` is left out; put a link or button inside it instead.

## Accessibility

- Give `BubbleReactions` an `aria-label` when it holds only emoji.
- Dither canvases are hidden from assistive tech.
