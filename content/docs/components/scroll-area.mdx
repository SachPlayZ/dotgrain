## Usage

```tsx
import { ScrollArea } from "@/components/ui/scroll-area";

<ScrollArea style={{ height: 200 }}>…</ScrollArea>
```

A vertical `ScrollBar` is built in. For sideways scrolling, add `<ScrollBar orientation="horizontal" />` as a child.

## Accessibility

- Scrolling stays native: wheel, touch and keyboard all work.
- Bar canvases are hidden from assistive tech.
