## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert";

<Alert>
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>You can add components with the shadcn CLI.</AlertDescription>
</Alert>
```

Put an icon first and it takes its own column beside the title and description; give it a right margin.

## Accessibility

- The root has `role="alert"`, so its text is announced when it appears.
- The frame canvas and the ✖ mark are hidden from assistive tech.
