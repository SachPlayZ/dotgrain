## Usage

```tsx
import { DropdownMenu, DropdownMenuContent, DropdownMenuItem, DropdownMenuTrigger } from "@/components/ui/dropdown-menu";

<DropdownMenu>
  <DropdownMenuTrigger>Options</DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuItem>Profile</DropdownMenuItem>
    <DropdownMenuItem>Settings</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

Wraps [Radix Dropdown Menu](https://www.radix-ui.com/primitives/docs/components/dropdown-menu) with all of shadcn's parts: groups, labels, checkbox and radio items, submenus, separators and shortcuts. Token props on `DropdownMenuContent` reach every item inside.

## Accessibility

- Radix handles the menu pattern: arrows, typeahead, Enter, Esc and focus return.
- The highlighted item's label sits on a solid chip over the dither, so contrast holds.
