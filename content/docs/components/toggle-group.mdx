## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group";

<ToggleGroup type="multiple" defaultValue={["bold"]}>
  <ToggleGroupItem value="bold">Bold</ToggleGroupItem>
  <ToggleGroupItem value="italic">Italic</ToggleGroupItem>
</ToggleGroup>
```

Wraps [Radix Toggle Group](https://www.radix-ui.com/primitives/docs/components/toggle-group). Items look like [Toggle](/docs/components/toggle).

## Accessibility

- Arrow keys move between items; each item has `aria-pressed` (multiple) or `role="radio"` (single).
- Labels are real text on solid chips.
