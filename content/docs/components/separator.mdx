## Usage

```tsx
import { Separator } from "@/components/ui/separator";

<Separator />
```

It is drawn in ─ or │ glyphs, so it follows the font, not the dither tokens. It stretches to its container without adding to its size; vertical ones need a parent with a height.

## Accessibility

- Decorative by default (`role="none"`), like shadcn.
- With `decorative={false}` it is a `separator` with `aria-orientation`.
