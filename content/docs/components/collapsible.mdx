## Usage

```tsx
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@/components/ui/collapsible";

<Collapsible>
  <CollapsibleTrigger>Show more</CollapsibleTrigger>
  <CollapsibleContent>Hidden content.</CollapsibleContent>
</Collapsible>
```

Wraps [Radix Collapsible](https://www.radix-ui.com/primitives/docs/components/collapsible). Open content hangs off a 4px dithered rail.

## Accessibility

- The trigger gets `aria-expanded` and `aria-controls`.
- Closed content is removed from the accessibility tree.
