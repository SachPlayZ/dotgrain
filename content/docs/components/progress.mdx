## Usage

```tsx
import { Progress } from "@/components/ui/progress";

<Progress value={33} />
```

A thin wrapper over [DitherProgress](/docs/components/dither-progress) under shadcn's name and props. `null` reads as 0.

## Accessibility

- `role="progressbar"` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`.
