## Usage

```tsx
import { AspectRatio } from "@/components/ui/aspect-ratio";

<AspectRatio ratio={16 / 9}>
  <DitherImage src="/hero.jpg" alt="…" style={{ width: "100%", height: "100%" }} />
</AspectRatio>
```

Layout only, like shadcn's: it draws nothing. Put a [DitherImage](/docs/components/dither-image) or [DitherField](/docs/components/dither-field) inside.

## Accessibility

- No semantics of its own; the content inside carries them.
