## Usage

```tsx
import { Popover, PopoverContent, PopoverTrigger } from "@/components/ui/popover";

<Popover>
  <PopoverTrigger>Open</PopoverTrigger>
  <PopoverContent>Place content here.</PopoverContent>
</Popover>
```

Wraps [Radix Popover](https://www.radix-ui.com/primitives/docs/components/popover) with `PopoverAnchor`. The panel renders in a portal and flips to stay on screen.

## Accessibility

- Esc or an outside click closes it; focus returns to the trigger.
- The trigger gets `aria-expanded` and `aria-controls` from Radix.
