## Usage

```tsx
import { Checkbox } from "@/components/ui/checkbox";
import { Label } from "@/components/ui/label";

<Label><Checkbox defaultChecked /> Email me updates</Label>

<Checkbox checked={value} onCheckedChange={setValue} aria-label="Select row" />
```

Wraps [Radix Checkbox](https://www.radix-ui.com/primitives/docs/components/checkbox), with the same API as shadcn's.

## Accessibility

- Radix renders a `<button role="checkbox">` with `aria-checked` (including `mixed`); Space toggles it, and `name` submits with forms.
- The fill canvas is `aria-hidden`; the ✓ is drawn on a solid chip so it reads over any fill.
