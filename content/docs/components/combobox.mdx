## Usage

```tsx
import { Combobox } from "@/components/ui/combobox";

<Combobox
  aria-label="Framework"
  options={[{ value: "next", label: "Next.js" }, { value: "remix", label: "Remix" }]}
/>
```

shadcn ships combobox as a recipe; here it is one component built from Popover and Command, which install alongside. Copy the file to change the trigger or item layout.

## Accessibility

- The trigger has `role="combobox"` and `aria-expanded`; name it with `aria-label` or a label.
- Typing filters; arrows move; Enter selects and closes; Esc closes and returns focus.
