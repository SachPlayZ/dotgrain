## Usage

```tsx
import { Item, ItemActions, ItemContent, ItemDescription, ItemTitle } from "@/components/ui/item";

<Item variant="outline">
  <ItemContent>
    <ItemTitle>Security alert</ItemTitle>
    <ItemDescription>New sign-in from an unknown device.</ItemDescription>
  </ItemContent>
  <ItemActions>…</ItemActions>
</Item>
```

Parts: `ItemGroup`, `ItemSeparator`, `ItemMedia` (`default`, `icon` or `image`), `ItemContent`, `ItemTitle`, `ItemDescription`, `ItemActions`, `ItemHeader`, `ItemFooter`. shadcn's `asChild` is left out; wrap the Item in a link instead.

## Accessibility

- `ItemGroup` is a `list`; give each Item `role="listitem"` when you use one.
- Dither canvases are hidden from assistive tech.
