## Usage

```tsx
import { Attachment, AttachmentContent, AttachmentDescription, AttachmentMedia, AttachmentTitle } from "@/components/ui/attachment";

<Attachment state="uploading">
  <AttachmentMedia>▤</AttachmentMedia>
  <AttachmentContent>
    <AttachmentTitle>brief.pdf</AttachmentTitle>
    <AttachmentDescription>Uploading…</AttachmentDescription>
  </AttachmentContent>
</Attachment>
```

Parts: `AttachmentGroup` (a row that scrolls sideways), `AttachmentMedia`, `AttachmentContent`, `AttachmentTitle`, `AttachmentDescription`, `AttachmentActions`, `AttachmentAction` (a small ghost button), `AttachmentTrigger` (makes the whole chip clickable). shadcn's `asChild` is left out.

## Accessibility

- `uploading` and `processing` set `aria-busy`; say what is happening in `AttachmentDescription` too.
- Give each `AttachmentAction` an `aria-label` ("Remove brief.pdf").
- Dither canvases are hidden from assistive tech.
