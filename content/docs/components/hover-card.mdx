## Usage

```tsx
import { HoverCard, HoverCardContent, HoverCardTrigger } from "@/components/ui/hover-card";

<HoverCard>
  <HoverCardTrigger href="https://dotgrain.space">@dotgrain</HoverCardTrigger>
  <HoverCardContent>Dither and ASCII components.</HoverCardContent>
</HoverCard>
```

Wraps [Radix Hover Card](https://www.radix-ui.com/primitives/docs/components/hover-card). The trigger is a link, so it works without the card.

## Accessibility

- Opens on hover and focus. It is for sighted mouse users: screen readers skip the card, so keep its content optional.
