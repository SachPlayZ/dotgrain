## Usage

```tsx
import { Toggle } from "@/components/ui/toggle";

<Toggle aria-label="Toggle bold">Bold</Toggle>

<Toggle variant="outline" pressed={italic} onPressedChange={setItalic}>Italic</Toggle>
```

Hovering hints a dithered fill; pressing dithers the face full. It wraps [Radix Toggle](https://www.radix-ui.com/primitives/docs/components/toggle), with the same API as shadcn's Toggle. For an on/off setting, use [Switch](/docs/components/switch).

## Accessibility and performance

- A native `<button>` with `aria-pressed`; the label is real DOM text on a solid chip, legible over any fill.
- The face canvas is `aria-hidden` and draws only while the fill eases.
