## Usage

```tsx
import { Pagination, PaginationContent, PaginationItem, PaginationLink, PaginationNext, PaginationPrevious } from "@/components/ui/pagination";

<Pagination>
  <PaginationContent>
    <PaginationItem><PaginationPrevious href="#" /></PaginationItem>
    <PaginationItem><PaginationLink href="#" isActive>1</PaginationLink></PaginationItem>
    <PaginationItem><PaginationNext href="#" /></PaginationItem>
  </PaginationContent>
</Pagination>
```

Plain links in a `nav`. The current page is a solid dithered chip; hover hints with a light wash.

## Accessibility

- The `nav` is labelled "pagination"; the active link has `aria-current="page"`.
- Previous and Next carry aria-labels; the ellipsis is hidden from assistive tech.
