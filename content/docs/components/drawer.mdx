## Usage

```tsx
import { Drawer, DrawerContent, DrawerHeader, DrawerTitle, DrawerTrigger } from "@/components/ui/drawer";

<Drawer>
  <DrawerTrigger>Open</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Contrast</DrawerTitle>
    </DrawerHeader>
  </DrawerContent>
</Drawer>
```

Wraps [Vaul](https://vaul.emilkowal.ski), as shadcn does. Drag it down by the dithered handle, or anywhere on the panel, to dismiss.

## Accessibility

- Vaul builds on Radix Dialog: focus trap, Esc to close, focus return.
- Give every drawer a `DrawerTitle`.
