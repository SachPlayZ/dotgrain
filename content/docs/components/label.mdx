## Usage

```tsx
import { Label } from "@/components/ui/label";

<Label htmlFor="email">Email</Label>
```

Wraps [Radix Label](https://www.radix-ui.com/primitives/docs/components/label). It has no canvas, so it pairs with any control.

## Accessibility

- A native `<label>`: clicking it focuses or toggles its control.
