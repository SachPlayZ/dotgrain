## Usage

```tsx
import { DatePicker } from "@/components/ui/date-picker";

<DatePicker aria-label="Due date" onValueChange={setDate} />
```

It closes on pick. For ranges or other layouts, compose [Popover](/docs/components/popover) and [Calendar](/docs/components/calendar) yourself, as shadcn's recipe does.

## Accessibility

- The trigger is a button that announces the popover; give it `aria-label` when no visible label points at it.
- Focus moves into the calendar and returns to the trigger on close.
