## Usage

```tsx
import { Marker, MarkerContent } from "@/components/ui/marker";

<Marker variant="separator">
  <MarkerContent>Today</MarkerContent>
</Marker>
```

Parts: `MarkerIcon` (hidden from assistive tech) and `MarkerContent`. The rules are box glyphs (`─`), so there is no canvas. shadcn's `asChild` is left out.

## Accessibility

- The icon and rules are decorative; the content carries the meaning.
