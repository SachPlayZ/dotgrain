## Usage

```tsx
import { Kbd, KbdGroup } from "@/components/ui/kbd";

<KbdGroup>
  <Kbd>⌘</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```

Both parts render `kbd` elements, so keys read as keyboard input.

## Accessibility

- Real `kbd` text; the frame canvas is hidden.
