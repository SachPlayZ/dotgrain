## Usage

```tsx
import { Badge } from "@/components/ui/badge";

<Badge variant="outline">New</Badge>
```

The label always sits on a solid patch, so it reads over any dither density. `destructive` can't be red in a one-palette system, so it adds a ✖ mark instead.

## Accessibility

- Plain inline text; the canvas is hidden from assistive tech.
- The ✖ mark on `destructive` is `aria-hidden`; say what is wrong in the text.
