## Usage

```tsx
import { NativeSelect, NativeSelectOption } from "@/components/ui/native-select";

<NativeSelect aria-label="Fruit">
  <NativeSelectOption value="apple">Apple</NativeSelectOption>
  <NativeSelectOption value="pear">Pear</NativeSelectOption>
</NativeSelect>
```

Use it where the platform picker matters, e.g. on mobile; use [Select](/docs/components/select) for a fully styled list.

## Accessibility

- A real `<select>`: the OS picker, keyboard and forms are native.
- The chevron and underline are decorative.
