## Usage

```tsx
import { Message, MessageContent, MessageHeader } from "@/components/ui/message";

<Message align="end">
  <MessageContent>
    <MessageHeader>You</MessageHeader>
    …
  </MessageContent>
</Message>
```

Parts: `MessageGroup`, `Message`, `MessageAvatar`, `MessageContent`, `MessageHeader`, `MessageFooter`. Pure layout: put a [Bubble](/docs/components/bubble), [Attachment](/docs/components/attachment) or [Marker](/docs/components/marker) inside, and an [Avatar](/docs/components/avatar) in `MessageAvatar`.

## Accessibility

- Put the sender's name in `MessageHeader` (or an `aria-label` on the Message) so each turn is attributed.
